## Problem: Two Sum (Easy)
**Link:** https://leetcode.com/problems/two-sum/

### Approach
Used a brute-force double loop to test every pair `(nums[i], nums[j])` until the sum equals target. Index results are dynamically allocated via `malloc`.

### Complexity
- **Time:** O(n²)
- **Space:** O(1)

### Notes
Tested locally in VS Code using negative array values before LeetCode submission.
